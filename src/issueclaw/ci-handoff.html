Local resume opens the saved conversation and restores its proposed patch in a separate checkout. Cloud continuation opens a new Claude cloud conversation with an excerpt of the saved messages; it is not the original session.

Both buttons use the installed Issueclaw launcher and your own GitHub and Claude sign-in. You can also resume locally, then choose Open in → Cloud in Claude Desktop.

The launcher shows authentication, expired-artifact or unsupported-cloud errors. It does not silently substitute an API key. Checkpoint coverage can stop before the agent's final unfinished turn.
